# Mobile UI repair notes

Small, reproducible frontend repair examples for React and Next.js projects. The cases below are synthetic examples, not client projects or measured customer outcomes.

## Start here

- [A fixed-width row that hides its action](notes/overflow-row.md)
- [A focused mobile verification checklist](notes/mobile-checklist.md)

No package installation, accounts, API keys or tracking are required to read these notes. They are educational examples, not accessibility certification or a complete application audit.

## Ask a technical question

Open an issue with a minimal public reproduction. Issues are public: never post private repository access, passwords, tokens, customer information, payment details or identity documents. No automatic scans are performed on submitted URLs.

## Optional help with your own frontend

Launch Patch offers a bounded, AI-assisted mobile review and up to two agreed frontend fixes delivered as a PR. [Scope and inquiry process](SERVICE.md). A scope inquiry is not a purchase, booking or promise to start work. Payment arrangements must be confirmed before accepting an order.
